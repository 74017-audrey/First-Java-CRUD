This project is a simple Java console application that demonstrates CRUD operations for managing student records.

CRUD stands for:

Create: Add a new student.

Read: View the student records.

Update: Modify an existing student's information.

Delete: Remove a student record.

Technologies Used

Java

Java Development Kit (JDK)

Git and GitHub

How to Run the Application

Install a Java JDK.

Download or clone this repository.

Open a terminal in the project folder.

Compile the application:

javac src/StudentManager.java

Run the application:

java -cp src StudentManager

Project Reflection

Working on this project helped me practise Java programming and understand how CRUD operations work. I also gained experience using Git and GitHub for version control, creating branches, committing changes, and collaborating through pull requests.

Notes

Student records are stored temporarily while the application is running. The records are not saved to a database.
